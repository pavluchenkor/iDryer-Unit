#### Druckparameter für Gehäuse:

  - Material ABS, ABS-CF, ABS-GF, PC, HTPLA

  - Linienbreite 0,6–0,8 (überprüfen Sie, dass beim Drucken scharfe Kammern entstehen)

  - Anzahl der Umfänge 1
  
  - Füllung 10–15 %

  - Füllmuster linear

  - Spielraum-Schließradius 0,02

# 組裝

此頁面描述了iDryer Unit外殼和電子產品的物理組裝。

!!! danger "警告! 高壓電氣設備工作"
    開始前，請仔細閱讀安全措施。

    iDryer Unit包含在110-230V電源電壓下工作的元件。不正確的連接或操作可能導致觸電、火災或設備故障。

!!! danger "電源電壓工作"
    所有110-230V連接工作必須在設備斷電的情況下進行。在首次啟動前，確保所有連接都正確隔離。有關更多詳情，請參閱[安全](safety.md)部分。

!!! warning "一般安全措施"
    - 在進行任何工作前斷開設備電源。
    - 不要觸摸暴露的帶電部件。
    - 在打開前檢查配線的完整性。
    - 不要使用損壞的外殼或裸露電線的設備。
    - 不要讓打開的設備無人值守。
    - 確保所有金屬外殼部件都正確接地。
    - 如果檢測到焦味、煙霧或外殼異常發熱，請立即關閉設備。
    - 避免濕氣或冷凝水接觸設備元件。
    - 使用斷路器或過載繼電器。
    - 所有連接必須考慮電氣隔離進行。
    - 如果您沒有電氣設備的經驗，請諮詢合格的技術人員。

!!! tip "開始前"
    首先在桌子上組裝系統而不安裝到外殼中，並驗證所有組件的功能。準備說明在"組裝前"部分。

## 需要什麼

- 打印的外殼 — [CAD: 模型和打印參數](cad.md)
- "組裝前"部分中零件清單中的所有組件
- 已編程和測試的Unit MCU電路板

## 逐步組裝

### 步驟1-4: 主室

<div class="grid cards" markdown>

1. 將卷軸架輥安裝在外殼底座中。
2. 將加熱元件安裝在指定位置。
3. 用墊片(左+右)固定加熱元件。
4. 將熱保護裝置KSD9700安裝到與加熱元件接觸的位置。

!!! warning "熱保護裝置KSD9700"
    確保KSD9700與加熱器外殼緊密接觸。接觸不良會降低緊急保護的可靠性。

### 步驟5-7: 通風和阻尼器

<div class="grid cards" markdown>
- ![5](../../img/005.jpg)
- ![6](../../img/006.jpg)
- ![7](../../img/007.jpg)
</div>

5. 將風扇安裝在外殼中並用緊固件固定。
6. 組裝阻尼器組件: 連接葉片和阻尼器外殼。阻尼器類型取決於使用的伺服系統(3.7克或9克)。
7. 將伺服連接到阻尼器。**此階段不要將阻尼器固定到外殼** — 伺服角度在編程後調整。

### 步驟8-10: 電子產品艙

<div class="grid cards" markdown>
- ![8](../../img/008.jpg)
- ![9](../../img/009.jpg)
- ![10](../../img/010.jpg)
</div>

8. 將控制板固定在電子產品艙中。
9. 安裝並連接電源連接器。對電源線使用USHVI端子。
10. 在電纜管道中佈置和固定傳感器電纜。安裝電子產品艙蓋。

!!! warning "熱敏電阻安裝"
    在加熱元件邊緣附近安裝熱敏電阻，大約在散熱器翅片高度的中點。

    熱敏電阻底部暴露的電線部分不應接觸加熱器的金屬外殼。如有必要，用卡普頓膠帶隔離這些區域或將其放在特氟隆管/熱收縮管中。

    加熱器溫度可達140°C。

## 組裝後

首次啟動前:

- [ ] 檢查所有連接的隔離。
- [ ] 確保電纜未被蓋子壓住。
- [ ] 確保熱開關與加熱元件良好接觸。
- [ ] 用萬用表檢查配線的完整性。

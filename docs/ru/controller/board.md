# Контроллер

Система строится на двух типах плат: основной блок MCU и блоки расширения EXT.

## iDryer Unit MCU

Основная плата с микроконтроллером. Управляет всей системой: читает датчики, управляет нагревателем, вентилятором и сервоприводом заслонки. Подключение к хосту — USB-C. Три разъёма RJ45 для подключения блоков EXT.

![Плата MCU](../../img/MCU_PCB.png)

## iDryer Unit EXT

Плата расширения без микроконтроллера. Подключается к MCU через RJ45-патчкорд и управляется им напрямую. На каждый дополнительный сушильный блок — одна плата EXT.

![Плата EXT](../../img/EXT_PCB.png)

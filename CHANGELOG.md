# Changelog

Этот файл ведётся на русском языке и фиксирует заметные изменения в проекте iDryer Unit — корпусе, механике и документации сушилки.

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [3.0.0]

### Добавлено

- **Второй сценарий работы: Standalone.** Сушилка работает сама по себе на прошивке iDryerControllerV2, управление идёт через портал и мобильное приложение, локально — через экран. Klipper остаётся как прежде, сценарий выбирается перед сборкой.
- **Единая аппаратная платформа.** iDryer Unit и iDryer X собираются на одном контроллере и одной прошивке.
- Комплектация с фотографиями, количествами и ссылками на заказ.
- Раздел частых вопросов.

### Изменено

- Конфигурации Klipper приведены в соответствие с числом контроллеров.
- Структура документации переработана, добавлены переводы.

## [2.x и ранее]

Серия пробных сборок и ранних вариантов корпуса. Направление завершено, наработки перенесены в 3.0.0.

# iDryer Unit

iDryer Unit — модульная система сушки и хранения филамента для 3D-принтеров. Печатаемый корпус на 1 или 2 катушки, до четырёх независимых сушильных камер в одной системе.

Температура сушки — до 90 °C в стандартном корпусе, до 110 °C при использовании теплостойких материалов корпуса. Поддерживаемые режимы — сушка (Drying), хранение (Storage) и профили (Profile).

![iDryer Unit](../img/iDryer.png)

## Для кого этот проект

iDryer Unit — DIY-проект для тех, кто хочет надёжную сушилку с реальным контролем над процессом, а не готовое коммерческое устройство с закрытой начинкой.

Все компоненты — стандартные и доступные: вентилятор, PTC-нагреватель, датчик температуры и влажности, сервопривод, Thermal Protector. Любой из них можно заменить без поиска фирменных запчастей. В отличие от большинства серийных сушилок, здесь нет ничего, что нельзя починить или улучшить.

Корпус печатается на любом 3D-принтере. Схемы, прошивки и документация открыты.

## Два варианта работы

Выберите сценарий до начала сборки — от него зависит прошивка и способ управления.

### Klipper

![Klipper](../img/klipper222252.jpg)

Контроллер Unit подключается к хосту принтера и работает как `[mcu]` или `[second_mcu]` в Klipper. Управление — через интерфейс Fluidd / Mainsail, макросы G-кода, интеграция с основным конфигом принтера.

Доступны дополнительные функции Klipper: уведомления через Telegram-бот (статус сушки, завершение цикла, перегрев), адресная светодиодная лента для визуальной индикации режимов, автологирование событий.

Подходит, если:

- у вас уже работает Klipper;
- хотите управлять сушилкой прямо из интерфейса принтера;
- нужна глубокая интеграция с макросами и расписанием.

→ [Прошивка Klipper](controller/firmware.md)

### Standalone

![iDryer Portal](../img/portal_screenshot.png)

Контроллер работает самостоятельно: своя прошивка, управление через облачный портал [portal.idryer.org](https://portal.idryer.org/) и мобильное приложение. Опционально — локальное управление через OLED-экран и энкодер. Поддерживаются весы (контроль остатка филамента по весу) и RFID (автоматическое определение катушки).

Подходит, если:

- хотите сушилку отдельно от принтера;
- нужен удалённый контроль через мобильное приложение или портал;
- используете несколько сушилок с одной точкой управления.

→ [Standalone: о прошивке](../../../iDryerRP2040/README.md)

## Характеристики

| Параметр | Значение |
|---|---|
| Температура сушки | до 90 °C (до 110 °C с теплостойким корпусом) |
| Режимы | Drying, Storage, Profile (Standalone) |
| Количество камер | 1–4 (MCU + до 3 × EXT) |
| Подключение модулей | RJ45 патчкорды |
| Thermal Protector | KSD9700 (130 °C) |
| Защита по току | предохранитель 2 А |
| Нагревательный элемент | PTC, полная электрическая изоляция |
| Катушки | 1 или 2 на камеру; ширина до 85 мм, диаметр до 200 мм |
| Варианты корпуса | На 1 катушку и на 2 катушки |
| Материал корпуса | Печатаемый, ABS / ABS-CF / PC / HTPLA |
| Датчик влажности | SHT3X или любой, поддерживаемый прошивкой |
| Светодиодная индикация | выход для адресной LED-ленты на плате MCU |

## Режимы работы

**Drying (сушка)** — задайте температуру и время. По истечении цикла система автоматически переходит в режим Storage.

**Storage (хранение)** — поддерживает заданную температуру и минимальный уровень влажности. Нагреватель и вентилятор включаются при превышении заданных параметров.

**Profile (профиль)** — пользовательские сценарии с настраиваемыми параметрами и переходами между режимами. Доступен в Standalone-прошивке.

## Управление влажностью

Каждая камера оснащена управляемой заслонкой. Сервопривод открывает заслонку по расписанию для вывода насыщенного влагой воздуха и закрывает её для удержания тепла. Датчик SHT3X непрерывно контролирует температуру и влажность внутри камеры — прошивка корректирует режим работы заслонки и нагревателя на основе этих данных.

## Архитектура системы

Один блок **iDryer Unit MCU** управляет системой. К нему напрямую через RJ45 подключаются до трёх блоков **iDryer Unit EXT** без собственного микроконтроллера.

```
              ┌— RJ45 — [EXT U2]
[MCU] ————————┼— RJ45 — [EXT U3]
              └— RJ45 — [EXT U4]
```

Каждый блок — независимая сушильная камера со своими датчиком, нагревателем, вентилятором и сервоприводом заслонки.

## Встроенная безопасность

- **KSD9700** — Thermal Protector на 130 °C: физически размыкает цепь нагревателя при перегреве.
- **Предохранитель 2 А** — защита при аварийных токах.
- **PTC-нагреватель** — корпус нагревателя не находится под напряжением.
- **Программная защита** — Klipper (или Standalone-прошивка) контролирует температуру, наличие датчиков и отключает нагрев при ошибке.

!!! danger "Работа с сетевым напряжением"
    Устройство содержит компоненты под напряжением 110–230 В. Перед любыми работами с электрикой отключайте питание. Подробнее — в разделе [Безопасность](unit/safety.md).
